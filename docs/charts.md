# 图表展示

入口 `/#/charts`，位于“组件示例”。页面包含访问趋势折线图、部门用户柱状图、用户状态环形图和部门角色堆叠条形图。

## 数据与交互

- 访问趋势是本地公式生成的演示序列，支持近 7 天／近 30 天切换，并非真实流量。
- 分布数据通过用户管理的 Mock 查询读取；新增、编辑或切换用户状态后，打开图表页或点击刷新即可更新。
- 角色采用多标签计数，一个用户可以计入多个角色，因此角色总数不一定等于用户总数。
- 环形图和堆叠图支持点击图例隐藏／恢复系列。
- 刷新展示加载状态，“空数据演示”只切换展示，不删除 Mock 记录。

## 组件边界

`src/components/EChart/index.tsx` 接收 `option`、`label` 和可选 `height`。只负责初始化、配置更新、尺寸适配和卸载销毁。`label` 用作图表的可访问名称。

组件按需注册折线、柱状、饼图及 grid、tooltip、legend、aria 和 CanvasRenderer；新增图表类型时按需补充注册。尺寸变化复用 `useDomChange`，关闭 DOM mutation 监听，避免图表自身绘制重复触发监听。

数据读取位于 `src/mock/charts.ts`，图表配置、加载与空状态位于 `src/views/ChartExamples`。数据请求复用 `useResource`，卡片、切换器、加载与空状态使用 Ant Design。
